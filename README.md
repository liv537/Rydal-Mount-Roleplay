# Rydal Mount Roleplay Drama Engine

A lightweight browser app for randomising boarding-school drama without repetitive outcomes.

## Included features
- Starter roster of students + staff (editable)
- Bulk import and one-by-one person creation
- Saved profiles (per user/story) in localStorage
- Random name picker
- Scenario coin flip (yes/no)
- Matchmaker + crush randomiser with safeguard: **no staff/student relationships**
- Pregnancy test for **female students only** with rerolls
  - Tracker appears only on positive tests
  - Track baby gender, baby count, trimester, bump size
- Custom wheels (name, entries, spin, delete) saved per profile
- Gossip generator + responses influenced by text you enter
- Group chat with teacup vibe ☕
- Random phone notifications (wheel spin / pregnancy gossip)
- Timeline/history log + one-click school calendar event loader

## Run
Open `index.html` in a browser.

No backend required.
